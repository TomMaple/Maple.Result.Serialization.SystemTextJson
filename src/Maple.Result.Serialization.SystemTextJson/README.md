# Maple.Result.Serialization.SystemTextJson
System.Text.Json converters that serialize and deserialize the [Maple.Result](https://www.nuget.org/packages/Maple.Result) types (`Result`, `Result<T>` and `Error`).

**In development:** no version is published yet. See the [repository](https://github.com/TomMaple/Maple.Result.Serialization.SystemTextJson) for the status.
